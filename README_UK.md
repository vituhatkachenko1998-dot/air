# Тривога UA — Android демо

Цей проєкт — початковий демонстраційний додаток для Android з трьома ручними станами:
- зелений — відбій (демо);
- жовтий — рівень уваги (демо);
- червоний — повітряна тривога (демо).

**Важливо:** додаток наразі НЕ отримує реальні дані й НЕ надсилає push-сповіщення. Кольори змінюються лише після натискання кнопок. Не використовуйте його як джерело інформації про небезпеку.

## Як зібрати APK
1. Встановіть Android Studio на комп'ютер.
2. Відкрийте папку `TryvohaUA` через **Open**.
3. Дочекайтеся Gradle Sync і встановлення потрібних компонентів Android SDK.
4. Оберіть **Build → Build APK(s)**.
5. APK зазвичай з'явиться в `app/build/outputs/apk/debug/app-debug.apk`.

Щоб зробити реальний сервіс, потрібно додати перевірене джерело даних, обробку помилок, дозволи сповіщень і тестування. Не можна вважати ручний демо-статус реальним попередженням.
